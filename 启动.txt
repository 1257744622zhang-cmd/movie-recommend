  1. 启动后端（Spring Boot，端口 8080）

  数据库配置在 backend/api/src/main/resources/application.yml，要求：
  - MySQL 地址 localhost:3306，数据库名 movie_recommend
  - 账号 root / 密码 123456

  先确保 MySQL 服务已启动，并创建数据库（任选其一）：
  - 用 Navicat/命令行执行 backend/movie_data.sql（会自动建库建表 + 导入 100 条电影数据），或
  - 手动 CREATE DATABASE movie_recommend;

  然后启动后端，在 backend 目录下：

  cd "C:\Users\zhd\Desktop\ai agent\cursor\电影推荐系统\backend"
  mvn clean install -DskipTests
  cd api
  mvn spring-boot:run

  ▎ 也可以在 IDEA 里直接运行
  ▎ MovieRecommendApplication（backend/api/.../com/movie/api/MovieRecommendApplication.java），它已经有 .idea 工程配置。

  看到 Tomcat started on port(s): 8080 即成功。

  2. 启动前端（Vite，端口 5173）

  新开一个终端：

  cd "C:\Users\zhd\Desktop\ai agent\cursor\电影推荐系统\frontend"
  npm install
  npm run dev

  （node_modules 已存在，npm install 一般会秒过；然后 npm run dev 即可。）

  浏览器打开 http://localhost:5173。前端已配置代理，/api 请求会自动转发到 http://localhost:8080。
